# My Life Calendar

Вид «Жизнь в неделях» для Obsidian: вся жизнь в виде сетки сердечек (52 колонки = недели года, каждая строка = год), со встроенным дневником, событиями и JSON-бэкапом (импорт/экспорт), совместимым с приложением **Life Calendar** (Android).

> Идея — «Life in Weeks» (WaitButWhy). Визуально совпадает с приложением Life Calendar для Android: прожитые недели — красные сердечки ♥, будущие — серые ♡, недели дня рождения — зелёные, события — сердечки в своём цвете, недели с записями отмечены жёлтой точкой.

## Установка

### Из каталога плагинов сообщества

1. В Obsidian: **Настройки → Сторонние плагины → Обзор**.
2. Найдите **Life Calendar** и установите его.
3. Включите плагин и при необходимости отключите **Режим ограничения**.

> Ручная установка (если плагин пока не виден в каталоге — например, пока заявка на рассмотрении):
>
> 1. Скачайте свежий релиз или соберите из исходников (см. ниже).
> 2. Скопируйте папку с `main.js`, `manifest.json`, `styles.css` в ваш vault:
>    `<ВашVault>/.obsidian/plugins/my-life-calendar/`
> 3. В Obsidian: **Настройки → Сторонние плагины → Обновить плагины** (или перезапустить Obsidian), затем включить **Life Calendar**.

## Первый запуск (онбординг)

При первом включении плагин запрашивает **дату рождения** (обязательно — от неё строится сетка). После сохранения плагин создаёт собственные папки, чтобы не конфликтовать с вашими заметками:

- `Life Calendar/Journal/` — записи дневника, файл на день (`DD.MM.YYYY.md`);
- `Life Calendar/Events.md` — события в YAML-frontmatter (`date`, `color`, `title`);
- `Life Calendar/backup.json` — файл JSON-бэкапа (импорт/экспорт).

Все пути настраиваются в настройках плагина.

## Возможности

- **Сетка жизни**: сердечки для каждой недели от даты рождения на весь срок жизни (по умолчанию 100 лет, настраивается 50–120).
- **Легенда**: дата рождения, сегодня, возраст (лет + нед.), число недель с записями.
- **Тултипы**: при наведении на сердечко виден текст записей недели. Для недель с записями открывается интерактивный тултип с палитрой цветов (8 цветов) и колец (8 цветов) — клик по образцу меняет цвет сердечка, повторный клик (или крестик «✕») сбрасывает. Настройки сохраняются и применяются на лету.
- **Клик по неделе**: открывает окно недели с записями дневника и событиями этой недели. У каждой записи есть кнопка **«📄 Открыть заметку»** — открывает файл дня.
- **➕ Запись в дневник**: дата + текст → дописывается в файл дня в `Life Calendar/Journal/`.
- **События**: добавление / редактирование / удаление (дата, название, цвет) через окно «События» или палитру команд. События отображаются на сетке цветными сердечками.
- **🎨 Зоны жизни**: отмечают периоды жизни (например, школа, университет, карьера) пастельным фоном на неделях, которые они охватывают. Открываются кнопкой «Зоны» в панели инструментов или палитрой команд: название, даты начала/конца, выбор пастельного цвета. При пересечении зон показывается цвет более поздней зоны; в тултип попадают все пересекающиеся зоны. Зоны хранятся в настройках и включаются в бэкап.
- **📤 Экспорт**: создаёт `Life Calendar/backup.json` в том же JSON-формате, который импортирует приложение Android (`version`, `birthDate`, `lifespanYears`, `entries`, `events`). Файл импортируется в приложении (Профиль → бэкап) или в другом vault Obsidian. С v1.4.0 зоны экспортируются отдельным ключом `zones` — Android-приложение его игнорирует (`ignoreUnknownKeys`).
- **📥 Импорт**: восстанавливает файл бэкапа в этом vault — записи дневника и события объединяются без дублей. С v1.4.0 зоны из бэкапа также импортируются (дубли по названию + датам начала/конца пропускаются). Опционально применяет дату рождения и срок жизни из файла (включено по умолчанию, если дата рождения ещё не задана). Удобно для переноса календаря на новый аккаунт Obsidian или восстановления из экспорта Android.
- **📜 Поток**: вся история дневника одним списком — кнопка «Поток» в панели инструментов открывает окно со всеми записями, сгруппированными по годам, месяцам и дням. Доступны поиск по тексту, фильтр по диапазону дат, фильтр «только с изображениями», переключение сортировки (сначала новые / сначала старые), а также открытие заметки дня (**📄**), редактирование, удаление и перемещение записей прямо из списка.
- **📊 Трекеры**: вкладка трэкера упражнений прямо в виде Life Calendar — кнопка «📊 Трекеры» в панели инструментов. Heatmap по месяцам (12 блоков × 7 дней недели), карточки статистики (итого, активных дней, лучшая серия, лучший день), таблицы по месяцам и неделям, детали дня по клику. Данные читаются из daily-заметок `daily/DD.MM.YYYY.md` в формате `Упражнение: число единица` (например, `Отжимание: 25`, `Бег: 5 км`). Записи добавляются кнопкой «➕ Добавить запись» и сохраняются в файл дня.
- **Команды** (палитра команд):
  - `My Life Calendar: Открыть Life Calendar`
  - `My Life Calendar: Добавить запись в дневник`
  - `My Life Calendar: События (добавить / редактировать / удалить)`
  - `My Life Calendar: Зоны (добавить / редактировать / удалить)`
  - `My Life Calendar: Экспорт резервной копии (JSON)`
  - `My Life Calendar: Импорт из резервной копии (JSON)`

## Зоны жизни

Зоны жизни позволяют отмечать периоды жизни — школа, институт, работа, свадьба и т.п. — сплошной пастельной полосой по неделям, которые они охватывают, чтобы сразу видеть, к какому этапу жизни относится каждая неделя.

### Как создать зону

1. Откройте вид **Life Calendar**.
2. Нажмите кнопку **🎨 Зоны** в панели инструментов или выполните команду `My Life Calendar: Зоны (добавить / редактировать / удалить)`.
3. В окне «Зоны» нажмите **➕** (добавить).
4. Заполните форму:
   - **Название** — например, «Университет» (обязательно);
   - **Дата начала** — день начала периода;
   - **Дата окончания** — день окончания периода (не может быть раньше начала);
   - **Цвет** — выберите один из 8 пастельных цветов палитры.
5. Нажмите **Сохранить**. Зона закрасится на сетке сплошной полосой: от сердечка, в которое входит дата начала, до сердечка с датой окончания.

### Редактирование и удаление

- **Редактировать**: откройте окно «Зоны» и кликните по строке зоны — откроется форма с теми же полями.
- **Удалить**: в окне «Зоны» нажмите **🗑** у нужной зоны.

### Как это выглядит

- Полоса — **сплошная заливка** позади сердечек: без разрывов между клетками и между годами.
- Заливка лежит на **самом нижнем слое** — смена цвета или подсветки сердечка никогда не скрывает зону под ним.
- **Пересекающиеся зоны**: если две зоны покрывают одни и те же недели, сверху показывается цвет зоны с **более поздней датой начала**; при наведении на такую неделю в тултипе перечисляются **все** пересекающиеся зоны (с их датами).
- Полоса зоны — только визуальная отметка: она не создаёт заметок и событий.

### Где хранятся зоны

Зоны сохраняются в настройках плагина. При **📤 экспорте** бэкапа зоны записываются в `backup.json` в ключ `zones` (цвет — ARGB, как у событий). **📥 Импорт** восстанавливает их тоже — зоны, которые уже существуют (то же название + даты начала/конца), пропускаются. Android-приложение игнорирует ключ `zones`, поэтому файл остаётся совместимым.

## 📜 Поток записей (Feed)

Поток — это единый хронологический список всех записей дневника из `Life Calendar/Journal/`. Он удобен, чтобы просмотреть всю историю целиком, найти запись по тексту или картинкам и отредактировать её, не открывая файлы вручную.

### Как открыть

1. Откройте вид **Life Calendar**.
2. Нажмите кнопку **📜 Поток** в панели инструментов.

### Что умеет

- **Группировка**: записи сгруппированы по годам → месяцам → дням; в заголовке дня показаны дата и день недели.
- **Поиск по тексту**: поле поиска фильтрует записи по содержимому (учитываются и вики-ссылки, и подписи изображений).
- **Фильтр по датам**: поля «С» / «По» ограничивают диапазон показа.
- **Только с изображениями**: чекбокс оставляет записи, содержащие `![[изображения]]`.
- **Сортировка**: переключатель ⬇/⬆ — сначала новые или сначала старые записи.
- **Действия с записями** (в правом верхнем углу карточки):
  - **📄** — открыть заметку дня (файл `DD.MM.YYYY.md`);
  - **▲ / ▼** — переместить запись вверх/вниз внутри дня (меняет порядок блоков в файле дня);
  - **✏️** — отредактировать дату и текст (сохраняются вики-ссылки и изображения);
  - **🗑** — удалить запись (с подтверждением).

В карточках записи отображаются как готовый Markdown: вики-ссылки кликабельны, изображения видны прямо в списке.

## 📊 Трекер упражнений

Вкладка трэкера упражнений встроена прямо в вид **Life Calendar** — отдельные плагины (Dataview и т.п.) не нужны.

### Как открыть

1. Откройте вид **Life Calendar**.
2. Нажмите кнопку **📊 Трекеры** в панели инструментов.
3. Кнопка **← Назад** возвращает к сетке жизни.

### Где хранятся данные

Записи читаются из daily-заметок (по умолчанию папка `daily/`, файлы `DD.MM.YYYY.md`). Формат строки: `Упражнение: число единица`, например:

```
Отжимание: 25
Бег: 5 км
Планка: 2 мин
```

Распознаются единицы: повторения, минуты (мин), килограммы (кг), километры (км), произвольные.

### Что умеет

- **Heatmap**: 12 блоков по месяцам, в каждом 7 дней недели; интенсивность цвета — 5 уровней от суммы значений за день. Сегодняшний день обведён. Клик по дню показывает детали снизу (записи дня), крестик закрывает.
- **Статистика**: всего, активных дней, лучшая серия (дней подряд), лучший день.
- **Фильтр по упражнению**: выпадающий список «Все» + каждое упражнение.
- **Год**: переключатель года (◀ ▶).
- **Таблицы**: итоги по месяцам и неделям (дней и суммарное значение).
- **➕ Добавить запись**: выбор упражнения (или своё название), значение, единица, дата — запись сохраняется в файл дня (существующая строка того же упражнения обновляется).

### Настройки

В **Настройках** плагина — раздел **«Настройки трэкера»**:
- **Папка daily notes** — где искать файлы `DD.MM.YYYY.md`;
- **Список упражнений** — добавление (название + единица по умолчанию), удаление, перестановка перетаскиванием.

## Настройки

- Дата рождения
- Продолжительность жизни (50–120 лет)
- Язык: авто (язык Obsidian) / русский / английский
- Пути: папка дневника, файл событий, файл экспорта
- Зоны жизни (добавление / редактирование / удаление через окно «Зоны»)
- Настройки трэкера: папка daily notes, список упражнений
- Сброс цветов/колец сердечек

## Разработка

Требуется Node.js ≥ 18.

```
npm install
npm run dev     # режим наблюдения
npm run build   # продакшен-сборка -> main.js
```
