# Life Calendar

Вид «Жизнь в неделях» для Obsidian: вся жизнь в виде сетки сердечек (52 колонки = недели года, каждая строка = год), со встроенным дневником, событиями и экспортом в один клик для приложения **Life Calendar** (Android).

> Идея — «Life in Weeks» (WaitButWhy). Визуально совпадает с приложением Life Calendar для Android: прожитые недели — красные сердечки ♥, будущие — серые ♡, недели дня рождения — зелёные, события — сердечки в своём цвете, недели с записями отмечены жёлтой точкой.

## Установка

> Ручная установка (плагин пока не опубликован в каталоге Obsidian).

1. Скачайте свежий релиз или соберите из исходников (см. ниже).
2. Скопируйте папку с `main.js`, `manifest.json`, `styles.css` в ваш vault:
   `<ВашVault>/.obsidian/plugins/obsidian-life-calendar/`
3. В Obsidian: **Настройки → Сторонние плагины → Обновить плагины** (или перезапустить Obsidian), затем включить **Life Calendar**.

## Первый запуск (онбординг)

При первом включении плагин запрашивает **дату рождения** (обязательно — от неё строится сетка). После сохранения плагин создаёт собственные папки, чтобы не конфликтовать с вашими заметками:

- `Life Calendar/Journal/` — записи дневника, файл на день (`DD.MM.YYYY.md`);
- `Life Calendar/Weekly/` — недельные заметки-агрегаторы (создаются по клику на неделю);
- `Life Calendar/Events.md` — события в YAML-frontmatter (`date`, `color`, `title`);
- `Life Calendar/backup.json` — файл экспорта для приложения Android.

Все пути настраиваются в настройках плагина.

## Возможности

- **Сетка жизни**: сердечки для каждой недели от даты рождения на весь срок жизни (по умолчанию 100 лет, настраивается 50–120).
- **Легенда**: дата рождения, сегодня, возраст (лет + нед.), число недель с записями.
- **Тултипы**: при наведении на сердечко виден текст записей недели. Для недель с записями открывается интерактивный тултип с палитрой цветов (8 цветов) и колец (8 цветов) — клик по образцу меняет цвет сердечка, повторный клик (или крестик «✕») сбрасывает. Настройки сохраняются и применяются на лету.
- **Клик по неделе**: открывает (или создаёт) недельную заметку-агрегатор, собранную из файлов дневника этой недели. Ручные секции, добавленные вручную, сохраняются при пересборке заметки.
- **➕ Запись в дневник**: дата + текст → дописывается в файл дня в `Life Calendar/Journal/`.
- **События**: добавление / редактирование / удаление (дата, название, цвет) через окно «События» или палитру команд. События отображаются на сетке цветными сердечками.
- **📤 Экспорт для Life Calendar Android**: создаёт `Life Calendar/backup.json` в том же JSON-формате, который импортирует приложение Android (`version`, `birthDate`, `lifespanYears`, `entries`, `events`). Дальше файл импортируется в приложении (Профиль → бэкап).
- **Команды** (палитра команд):
  - `Life Calendar: Открыть Life Calendar`
  - `Life Calendar: Добавить запись в дневник`
  - `Life Calendar: События (добавить / редактировать / удалить)`
  - `Life Calendar: Экспорт для Life Calendar Android`

## Настройки

- Дата рождения
- Продолжительность жизни (50–120 лет)
- Пути: папка дневника, папка недельных заметок, файл событий, файл экспорта
- Сброс цветов/колец сердечек

## Разработка

Требуется Node.js ≥ 18.

```
npm install
npm run dev     # режим наблюдения
npm run build   # продакшен-сборка -> main.js
```
